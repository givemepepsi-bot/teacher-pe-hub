기록과 개인정보 안내

2026-11-10 · 연수용 서비스의 기술적 데이터 처리 안내

공개 페이지와 개인 기록은 구분됩니다

GitHub Pages에는 프로그램 코드와 가상 예시 데이터가 게시됩니다. 입력한 학생 기록·JSON 백업·브라우저 DB는 공개 저장소나 사이트 파일에 포함하지 않습니다. 연수에서는 가상 별칭만 사용하세요.

로컬 체험

로그인하지 않은 체험 기록은 현재 주소의 브라우저 내부 저장소에 남습니다. 기기 사용자별 잠금은 없습니다. 공용 기기에서 실제 학생정보를 입력하지 마세요. 브라우저 데이터 삭제 시 기록이 사라질 수 있습니다.

선택적 구글 로그인과 클라우드

Firebase 연결이 설정되면 Google/Firebase가 계정 식별 정보·인증 토큰을 처리합니다. 앱은 이름·이메일·프로필 사진을 별도 DB에 복제하지 않고 화면에는 개인 계정의 로그인 여부만 표시합니다. 로그인 유지 범위는 현재 브라우저 세션입니다.

로그인만으로 로컬 기록을 업로드하지 않습니다. ‘내 클라우드 열기’를 선택하면 교사 본인의 비공개 저장 공간을 엽니다. 그 모드에서 저장하거나 백업을 복원하면 출석·일지·피드백·학생 별칭 등 현재 작업 기록이 Firebase에 전송됩니다. 화면의 저장 모드를 확인하세요. 다른 계정이나 비로그인 방문자는 본인의 기록을 읽을 수 없도록 서버 규칙을 적용해야 합니다.

삭제·백업

현재 모드의 전체 초기화는 해당 작업 기록을 비웁니다. 클라우드 원본 전체 삭제 기능이 제공되면 삭제 후 별도의 새 공간이 만들어질 때까지 새 기록만 저장됩니다. 다운로드한 백업, 다른 기기에 남은 로컬 파일, Firebase Authentication 계정은 별도입니다. 로그아웃해도 서버 원본과 기존 로컬 체험 기록은 삭제되지 않습니다.

수집을 피할 정보

연락처·생년월일·사진·건강정보를 요구하지 않습니다. 자유 서술란에도 민감정보를 적지 마세요. 광고·Analytics·외부 오류 내용 수집 기능은 사용하지 않습니다. 호스팅·인증·DB 제공자는 서비스 제공에 필요한 접속정보를 자체 정책에 따라 처리할 수 있습니다.

학교에서 실제로 사용하기 전

학교의 운영 주체, 실제 수집 항목·보존 기간·삭제 담당자·클라우드 처리 위치 및 필요한 안내·승인 절차를 정해야 합니다. 현재 안내는 법률 검토를 마친 개인정보 처리방침이나 학교 승인 자료가 아닙니다. 학생 계정별 제출·공개 공유는 이번 버전에 포함되지 않습니다.
