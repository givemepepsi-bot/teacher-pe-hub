# 체육쌤 허브

교사 기기 한 대에서 사용하는 연수용 프론트엔드 웹앱입니다. 프로그램 허브 안에 **스포츠클럽 퀘스트**를 제공합니다.

## Google 로그인과 개인 클라우드

- Google 로그인 후 **내 클라우드 열기**를 누르면 본인 계정의 비공개 기록을 엽니다.
- 로그인만으로 기존 로컬 기록을 업로드하지 않습니다. 새 계정의 클라우드는 빈 기록으로 시작합니다.
- 화면 상단에 현재 저장 모드를 표시합니다. 클라우드 모드에서 출석·일지·피드백을 저장하면 Firebase에 전송합니다.
- 기존 기록을 옮기려면 로컬 모드에서 백업한 뒤, 클라우드를 열고 본인이 선택한 백업 파일을 복원하세요.
- 로그아웃 시 클라우드 기록을 화면에서 지우고 로컬 체험으로 돌아갑니다. 서버 원본 삭제는 **클라우드 기록 삭제**로 별도 실행합니다.
- 다른 교사 계정에는 기록을 공유하지 않습니다. 학생별 온라인 제출·공동 편집은 포함하지 않습니다.

서버: Firebase Authentication(Google), 서울 `asia-northeast3` Cloud Firestore Standard. 관리자 키·비밀번호는 프론트엔드에 포함하지 않습니다. Firebase Web SDK는 Google 공식 CDN의 고정 버전 13.2.0에서 로딩하며, 로컬 체험과 별개로 로그인·클라우드에는 인터넷 연결이 필요합니다.

배포 전 검토: [SECURITY_REVIEW.md](SECURITY_REVIEW.md). 사이트의 [기록·개인정보 안내](privacy.html)를 확인하세요. 연수에서는 가상 데이터만 사용하세요.

## 바로 실행

1. `Start.cmd`를 더블클릭하세요. Node.js가 필요하며 현재 제작 환경에는 설치돼 있습니다.
2. 브라우저에서 **http://127.0.0.1:5173** 을 여세요. 실행 창은 앱 사용 중 열어 두세요.
3. 종료하려면 실행 창에서 `Ctrl+C`를 누르세요.

터미널에서는 이 폴더에서 `npm start`를 실행해도 됩니다. **앱 실행에는 npm install이 필요 없습니다.** `index.html`을 더블클릭하는 방식은 지원하지 않습니다.

## 연수용 체험 순서

1. 프로그램 허브 → **클럽 시작하기**.
2. **출석 체크** → 학생 상태 변경 → **출석 저장**.
3. **훈련일지** → 학생 선택 → 세 문항에 각각 5자 이상 작성 → **일지 완료하기**.
4. 같은 화면 아래 **교사 피드백** 저장.
5. **성장 순위** → 포인트·공동순위·누적 레벨 확인 → **발표 모드**.
6. **설정 · 백업** → 백업 다운로드. 다시 시연하려면 **예시 데이터로 되돌리기**.

첫 실행에는 가상 학생 28명, 클럽 2개와 회차별 예시 데이터가 제공됩니다. 출석·지각 10점, 참여한 회차의 완료 일지 10점으로 최대 20점을 얻습니다. 수정은 중복 가산하지 않습니다.

## 저장과 복구

- 현재 기기의 현재 브라우저, **동일한 접속 주소**의 IndexedDB에 저장됩니다.
- `localhost`와 `127.0.0.1`은 별개 저장 공간이므로 항상 위의 주소를 사용하세요.
- 새로고침·서버 재시작 후에도 브라우저 데이터를 지우지 않았다면 기록이 유지됩니다.
- 브라우저 데이터 삭제나 기기 변경에 대비해 JSON 백업을 내려받으세요.
- 복원은 검증 후 전체 기록을 교체합니다. 형식이 잘못된 파일은 기존 기록을 바꾸지 않습니다.
- 여러 탭이 같은 기록을 수정하면 오래된 탭의 덮어쓰기를 차단합니다. 입력을 복사하고 새 기록을 불러오세요.
- 계정·접근 잠금·학생별 온라인 제출은 없습니다. 공용 기기·연수에서는 **가상 데이터만 사용**하세요.

## 코드와 개발

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱 진입점 |
| `src/app.js` | 화면·대화상자·사용자 동작 |
| `src/styles.css` | 반응형 디자인 |
| `src/domain.js` | 명단·일지 검증·보상 계산·백업·데모 |
| `src/storage.js` | IndexedDB 원자 저장·충돌 검출 |
| `server.mjs` | 외부 의존성 없는 로컬 정적 서버 |
| `tests/` | 계산·복원·화면 검증 |
| `DEV_SPEC.md` | 요구사항과 향후 학생 접속 확장 방향 |

신속한 실행을 위해 최초 명세의 React/Vite 권장안 대신 브라우저 기본 HTML·CSS·ES Modules와 IndexedDB를 사용했습니다. 실행 시 외부 API·CDN·웹폰트·인증 서버에 의존하지 않습니다. 서버는 현재 기기의 loopback 주소에만 연결하며 기록 저장은 브라우저에서 처리합니다.

개발 검증:

```powershell
npm install
npm test
npm run check
npm run test:browser
```

브라우저 검사는 `npm start`가 실행 중이고 Microsoft Edge가 설치된 환경에서 수행합니다. 개발 검증 결과: 도메인·저장 테스트 14개, 실제 Edge 브라우저 시나리오 4개 통과. 화면 결과는 `artifacts/`에 있습니다.

개발용 패키지는 검증에만 사용합니다. 학생별 접속·공유는 이후 인증·서버 권한 검사·공유 저장소를 붙이는 별도 단계입니다. 현재 코드를 인터넷에 올려도 학생 기기끼리 자동 공유되지는 않습니다.
